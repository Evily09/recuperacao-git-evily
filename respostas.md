# Respostas - Git e GitHub

## 1. O que é um repositório?
É o local onde ficam armazenados os arquivos e o histórico de um projeto.

## 2. Qual a diferença entre Git e GitHub?
Git é o sistema usado para controlar as versões. GitHub é uma plataforma online que armazena e compartilha repositórios.

## 3. Para que serve um commit?
Serve para salvar uma alteração feita no projeto e registrar o que foi modificado.

## 4. Por que utilizamos branches?
Para desenvolver novas funcionalidades sem alterar diretamente a branch principal.

## 5. Qual a finalidade de um Pull Request?
Serve para solicitar que as alterações de uma branch sejam revisadas e adicionadas à branch principal.

## 6. Qual a diferença entre commit e push?
Commit salva as alterações no histórico local. Push envia essas alterações para o GitHub.

## 7. O que acontece quando um Pull Request é realizado?
As alterações são comparadas com a branch principal e podem ser revisadas antes do merge.

## 8. Qual a finalidade do merge?
É juntar as alterações de uma branch com outra, geralmente com a main.

## 9. Por que não é recomendado realizar todo o desenvolvimento diretamente na main?
Porque um erro durante o desenvolvimento pode afetar diretamente o projeto principal. As branches deixam o desenvolvimento mais organizado e seguro.
