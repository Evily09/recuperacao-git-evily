C

## Descrição do programa
O programa é um Sistema de Cadastro de Alunos. Ele permite cadastrar o nome, a idade e a nota de um aluno, exibir essas informações e informar se o aluno foi aprovado ou reprovado.

## Como executar o programa
O programa deve ser executado utilizando um compilador da linguagem C.

Exemplo:

gcc main.c -o programa

Depois execute:

./programa
